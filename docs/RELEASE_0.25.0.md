# Climb Studio 0.25.0

A quieter video-first workspace with stable timing controls and clearer review.

- One compact source chooser and athlete/attempt row; project video counts,
  missing-source recovery and keyboard video switching remain available.
- One transport row. Fit stays visible; Video options contains timeline range,
  preview preparation, cache explanation and focus view.
- Both hand timing columns stay above the scrolling Clips, Events, Points and
  Feet review views. Reviewing records cannot scroll away a running hand timer.
- Readable boundary values with explicit Edit menus: inspect, jump to the mark,
  replace it with the current frame or remove it. S/E still mark directly.
- Quiet toolbar actions, restrained command borders, activity accents and solid
  running timers. Keyboard focus is painted independently of checked choices;
  selected clipping methods also have a checkmark.
- Full-width Direct / Two-stage / Cannot tell choices and persistent pending
  counts. Unknown reasons, drafts and visibility-gap semantics are unchanged.
- Compact two-line event descriptions with activity/hand/search filters;
  selected filtered records retain their exact identity for edit and deletion.
- Add videos is the library's primary command. Batch preparation and assignment
  require a selection, with readable explanations when unavailable.
- Shared comparison scope/alignment is shown once. Athlete identities and frame
  status sit outside the footage; one shared timeline drives read-only tile lanes.
- Opening shows the filename and current indexing stage. Preview preparation
  explains local storage before starting and shows progress in the status bar.
- Matching report palette, lighter dashboard borders and updated guided tour.

Original hashes, frames, PTS, aspect ratios, cache mapping, recovery unions,
footwork eligibility and athlete/session identities are unchanged. There are no
new dependencies or cloud services. macOS and Windows installers are generated
and self-checked by the release workflow. Installed compatible versions can
update using Help → Check for updates.
