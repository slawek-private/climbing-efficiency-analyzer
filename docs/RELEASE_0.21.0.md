
## Coaching review and a calmer workspace

- Neutral light/dark surfaces, native platform fonts, System/Light/Dark appearance
  and increased contrast. A narrower, flatter inspector keeps the video prominent.
  Library's primary actions are Add and Prepare selected; queue/storage actions
  remain available under More.
- Projects open in the video library, with a clear count and Open now marker.
  Measure has numbered video navigation and a Viewing position indicator.
- Optional Footwork review: left/right/simultaneous slips, intentional releases,
  both-feet-off intervals, reviewed/obscured coverage and fall onset. Candidate
  observations and unknown coverage remain separate from confirmed measurements.
- Session goals, athlete reflection, attempt context, coach interpretation and
  agreed next-session actions.
- Local interactive coaching HTML with an evidence index, looping event/context
  replay, matched checkpoint comparisons, event/summary CSV, complete JSON snapshots
  and printable PDFs. Footage is excluded by default; choose original links or
  portable H.264 sections and stills explicitly. Prepared previews are reused.
- Background export with cancellation, source identity checks and recovery on
  publishing failure. Frame numbers and source PTS remain unchanged; no FPS
  interpolation or cloud inference. Updated recording tips and guided tour.
- Schema 1.3 is additive; an older-label backup is created before first overwrite.
  Keep schema 1.3 measurements on this version or newer. Existing rest/chalk union
  definitions remain unchanged.

See [the coaching guide](https://github.com/slawek-private/climbing-efficiency-analyzer/blob/main/docs/COACHING_REVIEW.md).
