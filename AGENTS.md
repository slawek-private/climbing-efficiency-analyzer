# Instructions for coding models working on this project

Read `README.md`, `docs/INSTALL_FOR_AGENTS.md`, `docs/MANUAL_VIEWER.md` and
`docs/REPORTS.md` before changing installation or measurement behaviour.

## Privacy

- Never commit or upload videos, people’s images, saved labels, athlete telemetry,
  preview caches, generated reports or screenshots containing real footage.
- Keep those assets in ignored `videos`, `labels`, `models`, `artifacts`, `output`
  or `tmp` directories. Historical footage-specific M0 reports stay ignored.
- `docs/screenshots` is an exception only for screenshots generated by
  `tools/capture_screenshots.py` with fictional labels and generated pixels.
  Do not copy a real app screenshot into that directory.
- Never commit credentials. Do not download weights without user approval.
- Do not use cloud inference or send footage to external services.

## Environment and portability

- Use Python 3.12.11 and uv 0.8.22, with `uv sync --locked` for the viewer.
- Install the Windows inference stack only when requested, using
  `uv sync --locked --extra analysis`. CUDA is optional and Windows-specific.
- Keep dependencies pinned and regenerate `uv.lock` for dependency changes.
- Use `pathlib`. Isolate platform-specific APIs in `viewer/platform_runtime.py`.
- Test with synthetic fixtures; never make tests depend on local private data.
- Do not claim M3 Pro or GPU validation based solely on Windows tests or wheel
  resolution. Explain what was actually checked.

## Correctness

- Preserve original video SHA256, frame numbers and presentation timestamps.
  Preview pixels may be compressed, but frames must map one-to-one to the source.
- Combined recovery is the interval union of dedicated rest and chalking across
  hands, clipped to climb boundaries. Count overlapping time once.
- Missing measurements remain unknown. Time outside marked recovery is
  unclassified, not measured movement. Timing does not establish causes of falls.
- Tests: `uv run --no-sync python -m pytest viewer -q`.
- Publication requires direct user authorization. Before any authorized push,
  inspect the staged file list and content for private data and credentials.
